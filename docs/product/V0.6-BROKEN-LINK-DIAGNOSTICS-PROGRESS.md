### Learning review

- Reuse the authoritative indexed occurrence set. A second regular-expression parser for broken-link checks would diverge from backlinks, code/fence exclusion, URI encoding and source offsets.
- Distinguish a missing target (`ENOENT`) from a path permission or offline failure (`unverified`) and never present a partial index as globally clean. Disk changes and dirty-tab edits must invalidate already-started scans.
- Main-process filesystem classification plus strictly typed sender-scoped IPC keeps the renderer read-only and avoids a new unreviewed filesystem boundary. Locate/Repair UI and editor mutation remain an explicit V06-07 responsibility.
- Keep the one worktree-local dependency install and local test discovery evidence separate from product Red; a slow full-suite bootstrap is not itself a product regression.

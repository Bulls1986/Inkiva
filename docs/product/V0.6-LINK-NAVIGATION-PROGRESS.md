## Stage 3 — Main/renderer integration (provisional; not release-accepted)

- Main `mt::format-link-click` now uses the existing canonical link parser to decode only after separating filename and fragment; invalid encoding raises a non-mutating user notice. `openFileOrFolder` carries a transient `navigationFragment` option through app, EditorWindow and renderer.
- Both new-tab and already-open-tab routes emit a typed `navigate-document-fragment` event. The renderer runs the established `whenRenderComplete` + explicit-user-interaction guard, refreshes the completed TOC, and uses the same-document navigation engine for the resolved destination; missing headings show a warning without writing bytes.
- Removed the transient `navigationFragment` from persisted tab-state construction; no extra filesystem/index authority added.
- **Additional executable Red:** escaped literal `\\#` was incorrectly treated as heading syntax; the callback produced `{ pathname: './Guide', fragment: 'Notes.md' }`. Changing split to skip escaped `#` passed the focused test.
- **Additional executable Red:** an emoji before `#` exposed `Array.from()` codepoint offsets being used against UTF-16 `slice()`, truncating `.md`. Switching to native string-index scanning passed the focused test.
- **Focused Green:** `node --test packages/desktop/test/unit/link-navigation-path.test.mjs` — 2/2 passed with the escaped-literal and emoji regression assertions included. `git -c core.whitespace=cr-at-eol diff --check` — passed.

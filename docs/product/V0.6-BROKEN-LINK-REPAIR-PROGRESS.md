### Retrospective / reusable engineering lessons

1. A modal releasing DOM text selection is expected browser behavior. Link repair must re-resolve its *logical source occurrence* on each user action using Muya public APIs, not trust a previous Locate/selection or bypass editor state through direct string replacement. This is specifically covered by the cancel-then-repair real Electron test.
2. Keep diagnostics read-only and revision-scoped, and distinguish missing targets from inaccessible/unverified ones. A partial result never means the workspace is clean; user-triggered Repair is the only mutation point and still uses existing Undo.
3. Validate dependency bootstrap separately from application behavior. `--ignore-scripts` omits Electron binary/natives; use a matching installed version at the minimum ignored package-local path and keep source/artifacts worktree-local. Do not classify an Electron launch failure as TDD Red or increase timeouts as a workaround.
4. Preserve the full release pipeline (unit, E2E, performance, three platforms package/install/updater smoke); record code-head CI verdict before merge and merge SHA only *after* actual remote verification.

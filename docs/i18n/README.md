# Historical upstream translations

The eleven `README-*.md` translations in this directory are **historical MarkText translations** inherited from the upstream project. They are intentionally retained as archival provenance, not current Inkiva product manuals. Their original links, platform promises, screenshots and licensing statements **must not** be used to describe Inkiva.

Current, maintained Inkiva information:

- [English Inkiva README](../../README.md)
- [简体中文 Inkiva README](../../README.zh-CN.md)
- [Inkiva 中文使用手册](https://www.inkiva.net/docs/zh-CN/introduction/)
- [English public documentation](https://www.inkiva.net/docs/introduction/)
- [Inkiva releases](https://github.com/Bulls1986/Inkiva/releases/latest)

The maintained product supports Windows x64 and macOS (Intel / Apple Silicon). It is distributed under GPL-3.0-or-later; the upstream MarkText MIT notices remain preserved for provenance, without changing Inkiva's project-level license.

**Maintenance rule:** new product claims, instructions and screenshots belong in `packages/website/content/docs/` and the authoritative root READMEs. If historical translations are reactivated, fully audit and update all links, platforms, releases, license wording and feature behavior first. Do not silently present an archived translation as current.

# 命令行界面

Inkiva 可通过已安装的应用可执行文件和命令行参数打开本地 Markdown 文件或文件夹。常见选项：

| 参数 | 说明 |
| --- | --- |
| `--debug` | 启用调试 |
| `--safe` | 忽略插件和部分用户配置 |
| `-n`、`--new-window` | 在新窗口打开 |
| `--user-data-dir` | 指定应用数据目录 |
| `--disable-gpu` | 关闭 GPU 硬件加速 |
| `--disable-spellcheck` | 本次运行关闭拼写检查 |
| `--version` | 显示版本 |
| `-h`、`--help` | 帮助 |

macOS 示例：

~~~sh
/Applications/Inkiva.app/Contents/MacOS/Inkiva --version
~~~

更多参数及平台限制见[英文命令行说明](https://www.inkiva.net/docs/cli/)。

# Inkiva 中文使用手册

Inkiva（墨映）是免费开源的所见即所得 Markdown 桌面编辑器，面向 **Windows x64、macOS Intel 和 Apple Silicon**。它直接打开、编辑并保存普通的 CommonMark / GitHub Flavored Markdown 文件，不需要账号、云服务或专有工作区格式。

## 从这里开始

1. [安装 Inkiva](./installation.md)，选择与你电脑匹配的安装包。
2. 阅读[基础操作](./basics.md)：文件、文件夹、标签页、大纲、保存和本地历史。
3. 阅读[编辑操作](./editing.md)：Markdown、表格、链接、反向链接和断链修复。
4. 按需配置[图片](./images.md)、[偏好设置](./preferences.md)和[快捷键](./key-bindings.md)。

如果遇到问题，先查看[常见问题](./faq.md)。本手册沿用桌面应用现有的功能入口；英文 UI 的实际菜单名称以当前安装版本为准。

## 重要原则

- 编辑内容始终是普通的 `.md` 或 `.markdown` 文件；索引、反向链接和大纲是辅助能力。
- **本地历史、自动保存和崩溃恢复不等于云备份或跨设备同步。** 重要文件仍需自行备份。
- 支持的正式安装平台仅为 Windows x64 和 macOS（Intel / Apple Silicon），不把 Linux 当作正式发布目标。
- 这里是中文操作指南；较长的技术参数表仍可查看[英文完整文档](https://www.inkiva.net/docs/introduction/)。

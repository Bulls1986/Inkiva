# 拼写检查

Inkiva 的拼写检查默认关闭。需要时在 **Preferences → Spelling** 中启用，并选择默认语言。拼写错误可以显示下划线，右键菜单可能提供更正、忽略或加入词典等选项，实际能力取决于系统和拼写服务。

## 配置说明

- `spellcheckerLanguage` 保存默认语言的 BCP-47 标记，例如 `en-US`、`de-DE`、`zh-CN`。
- 如果不想显示拼写下划线，可启用 **Don't underline misspelled words**。
- 更多词典的安装方式取决于操作系统或所选的 Hunspell 词典服务；部分下载需要联网。

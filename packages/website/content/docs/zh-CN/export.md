# 导出文档

Inkiva 可以将当前 Markdown 文档导出为 **PDF** 或 **HTML**，也可以使用系统打印功能。通过 **File → Export** 选择格式；这不会将原始 Markdown 文件变成其他专有格式。

## PDF 与打印选项

- **Page**：纸张大小、方向与边距。
- **Style**：字体、字号、行距、标题自动编号等。
- **Theme**：导出时的页面主题，与应用界面的 Light/Dark/Paper 外观不同。
- **Header and Footer**：可选择页眉、页脚布局并输入文字；当前不提供自动页码功能。

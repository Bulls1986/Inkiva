# 外观主题

Inkiva 提供三种内置应用外观：

- **Inkiva Light**：明亮的白色写作界面。
- **Inkiva Dark**：深色写作界面，适合低光环境。
- **Inkiva Paper**：暖纸色写作界面。

在 **Theme** 菜单或 **Preferences → Theme** 中选择。**Follow System Theme** 可让 Light 和 Dark 跟随系统状态；Paper 仍需手动选择。

这三种外观与**导出主题**是两类设置。导出 PDF/HTML 的样式应单独在导出窗口中调整。

![Light、Dark、Paper 主题预览](../assets/inkiva-settings-theme.png)

详细外观说明见[英文外观主题文档](https://www.inkiva.net/docs/themes/)。

# 快捷键

新用户配置默认采用 **Typora 风格快捷键**；也可以选择兼容 MarkText 的预设或按需自定义。下列是常见默认操作，修改预设后以应用当前设置为准。

| 操作 | Windows | macOS |
| --- | --- | --- |
| 新建标签页 | `Ctrl+N` | `Command+N` |
| 插入/编辑链接 | `Ctrl+K` | `Command+K` |
| 插入表格 | `Ctrl+T` | `Command+Option+T` |
| 标题 1–6 | `Ctrl+1`～`6` | `Command+1`～`6` |

在表格单元格内可以使用 **Shift+Enter** 输入硬换行。通过命令搜索可以寻找不熟悉的操作入口。

完整预设和自定义说明见[英文快捷键总表](https://www.inkiva.net/docs/key-bindings/)、[macOS 表](./key-bindings-macos.md)及[Windows 表](./key-bindings-windows.md)。部分历史 MarkText 风格快捷键不适用于默认 Typora 预设。

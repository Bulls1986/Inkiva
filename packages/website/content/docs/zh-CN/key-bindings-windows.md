# Windows 快捷键

Inkiva 在 Windows x64 上使用 **Ctrl**、**Alt**、**Shift** 等修饰键。新配置默认是 Typora 风格预设，较旧的 MarkText 预设可单独选择。

## 常用 Typora 风格操作

- `Ctrl+N`：新建标签页。
- `Ctrl+K`：插入或编辑链接。
- `Ctrl+T`：插入表格。
- `Ctrl+1`～`6`：切换标题级别。
- `Ctrl+单击`：有意跟随可编辑的文档链接。

使用[快捷键总览](./key-bindings.md)查看常见操作。完整 MarkText 兼容预设的菜单按键表参阅[英文 Windows 快捷键参考](https://www.inkiva.net/docs/key-bindings-windows/)。

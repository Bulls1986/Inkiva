# 导出主题

导出主题控制导出文档的排版，不会更改当前 Markdown 源文件或应用界面主题。Inkiva 提供 **Academic**、**GitHub**、**Liber** 三种导出样式。

## 安装与创建自定义主题

你可以将自定义 `.css` 文件放入[应用数据目录](./application-data-directory.md)下的 `themes/export/` 文件夹；部分情况下需要重新启动应用才会识别。

自定义主题的样式以导出 HTML 的 CSS 规则为基础。实际配置规范及主题文件示例请参考[英文导出主题说明](https://www.inkiva.net/docs/export-themes/)。

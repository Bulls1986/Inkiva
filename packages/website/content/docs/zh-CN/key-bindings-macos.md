# macOS 快捷键

Inkiva 在 macOS 上使用 **Command**、**Option**、**Shift** 等修饰键。新配置默认是 Typora 风格预设，不要将旧 MarkText 预设的按键直接当作现行默认值。

## 常用 Typora 风格操作

- `Command+N`：新建标签页。
- `Command+K`：插入或编辑链接。
- `Command+Option+T`：插入表格。
- `Command+1`～`6`：切换标题级别。
- `Command+单击`：有意跟随可编辑的文档链接。

按键可以通过偏好设置更改；查看[快捷键总览](./key-bindings.md)。完整 MarkText 兼容预设命令表及自定义字段见[英文 macOS 快捷键参考](https://www.inkiva.net/docs/key-bindings-macos/)。

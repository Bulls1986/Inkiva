# Environment

| Name                         | Description                                                 |
| ---------------------------- | ----------------------------------------------------------- |
| `INKIVA_DEBUG`             | Enable debug mode.                                          |
| `INKIVA_DEBUG_KEYBOARD`    | Print more keyboard information when debug mode is enabled. |
| `INKIVA_ERROR_INTERACTION` | Never show the error dialog to report bugs.                 |
| `INKIVA_PANDOC`            | Overwrite the pandoc path.                                  |
| `INKIVA_RIPGREP_PATH`      | Override the bundled ripgrep executable path.               |

## Development

| Name                     | Description                                                  |
| ------------------------ | ------------------------------------------------------------ |
| `INKIVA_EXIT_ON_ERROR` | Exit on the first error or exception that occurs.            |
| `INKIVA_IS_STABLE`     | **Please don't use this!** Used to identify stable releases. |
